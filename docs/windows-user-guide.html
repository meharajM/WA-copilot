AICA / Windows-first browser workspace

Install once. Work in your browser.

AICA uses a lightweight Tauri companion for Windows-native capabilities and a local agentd service for durable, authenticated operations. The product workspace stays in Edge or Chrome.

Build note: The repository publishes a verified browser bundle and unsigned Windows installers. Windows packaging is produced by the public Windows runner workflow for Credential Manager/migration sidecars; installers remain unsigned until release signing completes.

Download verified browser bundle · Download NSIS setup · Download MSI · SHA-256 manifest · View migration PR

Verify a download in PowerShell with Get-FileHash '.\AICA Native Host_1.0.0_x64-setup.exe' -Algorithm SHA256 and compare it with the manifest. The public Windows package workflow also uploads a commit-specific unsigned NSIS/MSI artifact.

1. Download and install

  1. Use the signed release installer for normal distribution. The branch links above are unsigned evaluation artifacts.
  2. Install per user and launch AICA Native Host.
  3. The companion starts agentd on a loopback-only, per-run port.

2. Open and pair the browser

Use Open browser workspace in the companion. Enter the one-time six-digit code shown by the companion, then select Pair browser.

3. Use the browser workspace

After pairing, use the browser for dashboard, chat, conversations, knowledge, lead directory, Email drafts, MCP, settings, and autonomy.

4. Configure channels

WhatsApp

Open Settings → WhatsApp Business. Connect Baileys or Cloud transport. Verify the account before enabling response permission or autonomous mode.

Email

Open Settings → Email Channel. Save secure transport settings, keep Draft Mode on, test the connection, then enable polling.

5. Post-setup behavior

  • Browser actions call authenticated local agentd APIs.
  • Agentd persists sessions, drafts, queues, recovery state, notifications, and delivery history.
  • Draft approval gates outbound sends.
  • Tauri handles only native seams: lifecycle, tray, OS credentials, folder reveal, and diagnostics. Browser offline speech uses the authenticated agentd/Vosk path.
  • Gmail IDs and SMTP RFC Message-IDs provide correlation, not final-delivery proof.

6. Restart and troubleshoot

  1. Restart the native companion and open the new workspace URL it reports.
  2. Pair again only when the session expired.
  3. For “Local service unavailable,” start the companion and refresh.
  4. For revoked credentials, use native reauthentication or provider sign-in.
