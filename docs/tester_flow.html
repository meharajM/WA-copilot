System Technical Reference

AIConsumerAgent v1.2 • Browser-first migration reference

1. Infrastructure Overview

The supported product workspace runs in Windows Edge or Chrome and connects to a paired, owner-supervised agentd service on the same machine. The lightweight Tauri companion supplies native OS capabilities such as keychain access, file/folder dialogs, lifecycle controls, and diagnostics. Electron remains a transition client while browser and agentd parity is completed.

1.1 Compute Layer

The browser communicates with agentd over authenticated loopback HTTP. Agentd owns durable product state, provider/channel workers, and background credentials; the browser owns the product UI. The native host does not mount a second product workspace or proxy arbitrary commands.

1.2 Persistence Layer

Persistence is handled by the daemon-owned SQLite 3 database and authenticated service routes. Browser sessions do not use renderer localStorage as a second authority, and credential values remain in the OS-backed store. Redacted audit exports are available through the browser; native file-path reveal remains desktop-only.

3. Detailed Architecture Flowchart

The current browser-first path keeps the product UI in Edge/Chrome and reserves Tauri for native OS capabilities.

Edge Detection
🌐 Browser workspace
Edge/Chrome renders the product after authenticated loopback pairing. The page never receives daemon bearer secrets or OS credential values.
Governance Layer
🧭 Local agentd boundary
Agentd owns sessions, SQLite state, credential-backed workers, bounded routes, CSRF/session checks, and provider/channel policy.
Intelligence Engine
🧠 Provider and channel workers
Browser chat streams through authenticated agentd providers; bounded knowledge and memory routes are available, while unsupported binary and disallowed/internal MCP operations fail closed.
Engagement Layer
🪟 Native companion
Tauri supplies only native diagnostics, owner pairing handoff, keychain presence/write flows, file/folder dialogs, and lifecycle controls. It does not render the product workspace.
💡 Tester boundary Validate the browser workspace and the native companion separately. A real Tauri window should show diagnostics/onboarding only; use Edge or Chrome for chat, settings, channels, knowledge, memory, and approvals. Electron remains the transition fallback until parity and Windows release gates are complete.
