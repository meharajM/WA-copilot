1. Infrastructure Overview

AIConsumerAgent is a multi-process Electron application designed for privacy-first, self-hosted WhatsApp automation. Unlike cloud-based SaaS solutions, the application runs entirely on your local hardware, keeping all Signal Protocol keys and SQLite databases under your direct control.

1.1 Compute Layer

The system utilizes Electron IPC (Inter-Process Communication) to separate heavy LLM reasoning and WhatsApp bridge activities. The Main Process handles raw network sockets and WhatsApp Signal sessions via Baileys, while the Renderer Process manages the React-based UI and the asynchronous Agent Runtime.

1.2 Persistence Layer

Persistence is handled by SQLite 3 with FTS5 (Full-Text Search) enabled. All conversation histories and learned entities are stored locally. For high-availability auditing, the system mirrors state to JSON audit logs located in the Library/Application Support directory.

3. Detailed Architecture Flowchart

The following diagram outlines the path of a customer message from the Edge to the Reasoning Engine.

Edge Detection
📱 Inbound Customer Entry
Baileys captures upsert.messages event. Signal keys are looked up from the local SQLite key-store.
Governance Layer
🛡️ deduplication & security
Message hash is checked against a 10-minute sliding window. Spam filter determines if the sender is blacklisted.
Intelligence Engine
🧠 Agent Reasoning Loop
The Agent performs a recursive search: (1) Check PDF knowledge, (2) check Memory Facts, (3) execute LLM reasoning.
Engagement Layer
⏳ Anti-Ban Delivery
Gaussian Jitter (8s-45s) is injected. The message is signed and pushed back to the WhatsApp Cloud via the local session.
💡 Developer Note for Testers If you encounter "Double Messaging," please check if your linked phone has a weak data connection. The app uses an optimistic sync mechanism that can occasionally trigger a retry if the cloud ACK is delayed.
